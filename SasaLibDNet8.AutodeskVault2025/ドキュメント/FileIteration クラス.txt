Autodesk.DataManagement.Client.Framework.Vault.Currency.Entities ネームスペース
FileIteration クラス

公開されるメンバー
プロパティ

パブリック・プロパティ Category このファイルに割り当てられているカテゴリを取得します。 
パブリック・プロパティ CheckedOutMachine ファイルをチェックアウトしたコンピュータのネットワーク ID を取得します。このプロパティは、IsCheckedOut が真の場合にのみ有効です。 
パブリック・プロパティ CheckedOutSpec ファイルがチェックアウトされたクライアントのコンピュータ上のパスを取得します。このプロパティは、IsCheckedOut が True の場合にのみ有効です。 
パブリック・プロパティ CheckedOutUserId ファイルをチェックアウトしたユーザの ID を取得します。このプロパティは、IsCheckedOut が True の場合のみ有効です。 
パブリック・プロパティ CheckInDate ファイルがチェックインされた日時を取得します。このプロパティは、IsCheckedOut が false の場合のみ有効です。 
パブリック・プロパティ Checksum 物理ファイルのチェックサムを取得します。これは IsCheckedOut が false の場合のみ有効です。 
パブリック・プロパティ Comment ユーザーによって設定されたコメント文字列を取得します。IsCheckedOut が true の場合、このプロパティにはチェックアウト時に設定されたコメントが含まれます。そうでない場合は、チェックイン時に設定されたコメントが含まれます。 
パブリック・プロパティ CreateDate このバージョンのファイルがボールト内で作成された日時を取得します。ファイルの最初のバージョンの場合、この日付は CheckInDate と一致します。それ以降のバージョンでは、この値は前のバージョンがチェックアウトされた時刻になります。 
パブリック・プロパティ CreateUserName このファイルをチェックインまたはアップロードしたユーザーの名前を取得します。 
パブリック・プロパティ DesignVisualizationAttachmentStatus ファイルのデザインビジュアライゼーションの添付状態を取得します。 
パブリック・プロパティ EntityClass このファイルに関連付けられているエンティティ・クラスを取得します。 
パブリック・プロパティ EntityIterationId このファイルのイテレーション ID を取得します。 
パブリック・プロパティ EntityMasterId このファイルのマスター ID を取得する。 
パブリック・プロパティ EntityName このファイルの記述名を取得する。この値は、ファイルのすべてのバージョンに適用される。 
パブリック・プロパティ FileClassification ファイルの分類を取得する。 
パブリック・プロパティ FolderId ファイルがチェックアウトされたフォルダの ID を取得します。このプロパティは、IsCheckedOut が真の場合にのみ有効です。 
パブリック・プロパティ IsCheckedOut このファイルの最新バージョンがチェックアウト状態にあるかどうかを取得する。ファイルがチェックアウトされるたびに、新しいバージョンがプレースホルダとして作成されます。 
パブリック・プロパティ IsCheckedOutToCurrentUser このファイルが、現在ログインしている金庫のユーザーに対してチェックアウトされているかどうかを取得します。 
パブリック・プロパティ IsCloaked このファイルがクロークされているかどうかを取得します。クロークされたオブジェクトとは、呼び出し元が閲覧権限を持っていないオブジェクトのことです。クロークされたファイルで有効なデータは、EntityIterationId と EntityMasterId だけです。その他のデータはすべて NULL または 0 になります。 
パブリック・プロパティ IsControlledByChangeOrder ファイルが変更命令によって制御されているかどうかを取得します。 
パブリック・プロパティ IsHidden このファイルをユーザに非表示にするかどうかを取得する。 
パブリック・プロパティ IsLatestVersion このファイルが最新バージョンであるかどうかを取得する。 
パブリック・プロパティ IsLocked ログインしているユーザがファイルを変更できるかどうかを取得する。 
パブリック・プロパティ IsOnSite ファイルがローカルサイト上にあるかどうかを取得します（マルチサイト環境では）。この値は、シングルサイト環境では常に真になります。 
パブリック・プロパティ IsOutOfDate このファイルを更新する必要があるかどうかを取得します。 
パブリック・プロパティ LastModifiedDate 物理ファイルの最終更新日を取得します。この値は、ファイルをアップロードしたクライアントによって設定されます。 
パブリック・プロパティ LifecycleInfo このファイルに関するライフサイクル情報を取得します。 
パブリック・プロパティ LinkInfo これがファイルへのリンクであるかどうかを取得します。値が NULL でない場合、LinkInfo はこのファイルへのリンクに関する情報を提供します。 
パブリック・プロパティ MaxCheckedInVersionNumber 現在金庫にチェックインしているファイルの最大バージョンを取得します。 
パブリック・プロパティ Parent この FileIteration の親フォルダを取得または設定します。 
パブリック・プロパティ RevisionInfo このファイルに関するリビジョン情報を取得します。 
パブリック・プロパティ Size このファイルのサイズ（バイト数）を取得します。 
パブリック・プロパティ VaultConnection このファイルが関連付けられているVault Connectionを取得します。 
パブリック・プロパティ VersionNumber ファイルのバージョンを取得します。Vault に追加されたばかりのファイルの VerNum は 1 です。
